# aLNP Explorer and database

Literature-derived database, interactive explorer and baseline machine-learning code for **augmented lignin nanoparticles (aLNPs)**: lignin nanoparticles carrying metals (Au, Ag, Cu, Co), metal oxides, other inorganics, organic molecules, polymers or biomolecules.

Every value is taken from a published paper. Nothing in this repository comes from unpublished or in-house measurements. Each record keeps its `paper_id`, source page and an extraction confidence, so it can be traced and checked against the paper.

**Status: prototype, not yet peer checked.** Records were extracted semi-manually; confidence below 0.6 flags values read from figures or otherwise uncertain.

**Live explorer:** https://zacadesanya.github.io/aLNP/.
